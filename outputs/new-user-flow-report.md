# Проверка пути нового пользователя

11 октября 2026. Проверен путь: лендинг → регистрация → первая запись → разбор → выбор рекомендации → повторная запись → второй разбор → история и новая тема.

## Что исправлено

| Где возникала неопределённость | Как теперь работает |
| --- | --- |
| Лендинг обещал выступление и вопросы, а знакомство начиналось со сложной настройки | Лендинг объясняет короткую первую попытку. Вопросы аудитории остаются дополнительным сценарием |
| После регистрации конкурировали готовое упражнение и большая форма | Основное действие — «Записать первую минуту». Тема и время уже выбраны, самостоятельная настройка раскрывается отдельно |
| Было непонятно, что происходит после сохранения | Кнопка называет следующий шаг: вопросы, следующий ответ или разбор. Приложение переходит туда автоматически |
| Во время обработки терялось понимание текущего этапа | Этапы тренировки видны на экранах записи, обработки и разбора. Сохранение и возможность вернуться через историю объяснены |
| Повтор забирал первую рекомендацию без выбора пользователя | В разборе можно выбрать главное наблюдение или конкретную рекомендацию. Выбранный текст становится фокусом новой записи; тема и длительность сохраняются |
| Завершение знакомства повторно открывало тот же отчёт | Переходы ведут к повторной записи или новой теме и завершают онбординг |
| Чтение условий могло увести с заполненной регистрации | Условия раскрываются внутри формы. Поля сохраняются, чтение условий не включает согласие автоматически |
| При сбое запуска обработки можно было принять запись за потерянную | Запись остаётся сохранённой; сообщение указывает конкретную кнопку продолжения |

Использованы общие правила интерфейса: естественные переносы, заголовки без конечных точек, кнопки без стрелок, обычная нумерация этапов, иерархия текста и отступ стрелки внутри select. Существующая светлая фотографическая иллюстрация сохранена.

## Проверено

- Новый тестовый аккаунт прошёл основной путь в браузере. Получены два настоящих разбора с `demo:false`, первый и повторный; обе записи доступны после обновления страницы и в истории.
- Для повторной попытки выбрана вторая опция. Чтением из тестовой базы подтверждены точный перенос выбранного фокуса, прежние тема и длительность, завершение онбординга и отсутствие дублирующих заданий.
- Дополнительный сценарий с вопросами: сохранение речи, ошибка запуска задания, обновление страницы, продолжение, три настоящих вопроса, сохранение первого ответа и автоматический переход ко второму. Полный цикл со всеми тремя ответами в этой проверке не повторялся.
- Сбой запуска задания смоделирован блокировкой только этого запроса в тестовой вкладке. Загрузка аудио осталась доступной. После снятия блокировки продолжение сработало без повторной записи.
- Условия регистрации раскрываются без перехода и потери заполненных полей; согласие остаётся выключенным. На ширине 390 CSS px форма и панель повторной попытки не имеют горизонтального переполнения. У select сохранены правый отступ 52 px и положение стрелки за 18 px от края.
- На экране настоящего разбора нет точек в конце заголовков, принудительных переносов внутри заголовков или стрелок в CTA. Ошибок JavaScript в финальной тестовой вкладке не обнаружено.
- Автоматические проверки: 51 тест прошёл; синтаксис обоих JavaScript-модулей, форматирование изменённых файлов и `git diff --check` проходят. Есть предупреждение тестовой HTTP-библиотеки, ошибок тестов нет.

Проверка выполнена в отдельной локальной базе. Источник звука — синтетическая тестовая речь через настоящий браузерный MediaRecorder. Передача в сервис расшифровки и нейросеть была реальной. Личные записи и основной аккаунт пользователя не менялись. Подмена источника звука и сетевая блокировка удалены, тестовый сервер остановлен.

Основное приложение доступно на http://localhost:8080/. Физический микрофон и физические мобильные устройства в этой проверке не использовались. Эта проверка подтверждает локальный путь пользователя; внешний production deployment ею не подтверждается.
