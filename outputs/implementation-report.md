# Отчёт о реализации пилота

11 октября 2026. Результат: приложение работает локально на **http://localhost:8080/**. Реальный AI подключён. Можно создать свой аккаунт, записать выступление, получить разбор и вернуться к истории.

## Выполнено

Три субагента работали параллельно по отдельным наборам файлов: backend/API/доступы, транскрибация и LLM, интерфейс и пользовательский путь. Основной агент согласовал контракт, подготовил запуск и обслуживание, выполнил реальные запросы, браузерную проверку, нагрузочный тест и итоговый аудит.

| Этап пользователя | Реализованный результат |
|---|---|
| Главная → начало | Новый лендинг, понятное предложение, открытый пример реального формата разбора, переход к регистрации |
| Аккаунт | Регистрация, вход/выход, хеширование пароля, серверная сессия, CSRF и ограничения попыток |
| Доступы | Изоляция тренировок, заданий, истории и медиа по владельцу; приглашения в production |
| Онбординг | Упражнение на минуту → разбор → один фокус → повторная попытка; возможность пропустить знакомство |
| Запись | MediaRecorder, уровень звука, таймер, прослушивание, скачивание, сохранение на сервере |
| Вопросы | Три вопроса по распознанному содержанию; ответы записываются отдельными сегментами |
| Разбор | Реальная расшифровка и LLM; проверенные цитаты, рекомендации, критерии и измеренные показатели |
| Возвращение | Приватная история с пагинацией, восстановление после обновления, фоновые задания и повтор после ошибки |
| Управление данными | Удаление тренировки, приватное аудио, скачивание разбора, одноразовое восстановление доступа через организатора |
| Обратная связь | Оценка и комментарий сохраняются на сервере |
| Эксплуатация | Метрики/ошибки/расход AI, выгрузка JSON/CSV, health/readiness, backup/restore, Dockerfile и документация |

Гостевой режим сохранён: запись остаётся в памяти вкладки, без отправки на сервер и без фиктивного AI-разбора. Для внешнего пилота выбран вход по приглашению; автоматическая почтовая верификация и восстановление ещё не подключены.

## Проверено

- **51 автоматический тест проходит**: доступы двух аккаунтов, сессии, CSRF, приглашения, восстановление, загрузки, дубли, задания, перезапуск, ошибки провайдера, подтверждение цитат, резервные копии и полный HTTP-цикл с фоновым worker.
- JavaScript syntax, Python compilation и `git diff --check` проходят. В тестовом клиенте есть предупреждение о будущей замене HTTP-библиотеки; ошибок тестов нет.
- Реальный провайдер: `whisper-large-v3` и `gigachat-3-pro`. Успешны разбор речи, вопросы и разбор четырёх сегментов; результаты сохранены с `demo:false`.
- В браузере: вход, создание тренировки, настоящий MediaRecorder на синтетическом звуке, остановка по таймеру, сохранение, обновление страницы, реальный AI-отчёт, отзыв, завершение онбординга и повтор. Тестовая подмена источника звука удалена обновлением страницы. Системный микрофон пользователя не использовался.
- Аудио WebM после сохранения имеет конечную длительность и пригодно для перемотки. Проверены мобильная компоновка экрана тренировки на 390 CSS-пикселях и отсутствие горизонтального переполнения. Физические мобильные устройства и их разрешения на микрофон ещё не проверялись.
- Резервная копия восстановлена в отдельное хранилище: проверены вход, история, два настоящих отчёта и приватные медиа.
- Нагрузочный тест: 920 настоящих HTTP-запросов, ступени 1/5/10/20/40 RPS, **0 ошибок**. На 10 RPS p95 — **14.05 мс**. Профиль — обычный API с записью метрик; это не тест генерации AI на 10 RPS.

## Найденные и исправленные ошибки

1. Неверные идентификаторы моделей — заменены на полученные из актуального `/models`.
2. Модель меняла или склеивала цитаты — теперь выбирает идентификатор, сервер подставляет точный исходный фрагмент. Критерии также привязаны к исходным пользовательским формулировкам.
3. Соединения SQLite не закрывались гарантированно — исправлено.
4. Multipart мог обрабатываться до проверки размера/доступа — добавлены ранние проверки, пределы тела/времени и параллельных загрузок.
5. Записанный браузером WebM не содержал конечной длительности — добавлена финализация контейнера без перекодирования звука.
6. Небезопасные случаи удаления, выгрузки, подсчёта DAU и расхода при ошибках — исправлены и покрыты проверками.
7. Резервная копия могла принять непроверенный файл или пропущенную запись — проверяется полный manifest, ссылки, содержимое и восстановление в новый каталог.
8. Потеря состояния после загрузки, повторные клики, истечение сессии, ограничения общей длительности, гонки отмены FFmpeg и видимость фокуса повторной попытки — исправлены.

## Что остаётся до внешних пользователей

- Предоставить hosting/домен и настроить внешний HTTPS, постоянное хранилище, секреты и перезапуск. Внешний deployment ещё не выполнен; Dockerfile подготовлен, сборка контейнера не подтверждена.
- Указать контакт организатора, срок хранения и правила участия, включая решение об участии несовершеннолетних; согласовать текст обработки данных.
- Получить тарифы/квоты агрегатора. Расходы и формула cost/DAU подготовлены; денежная стоимость пока не подтверждена.
- На внешнем адресе проверить запись с реального микрофона на desktop/mobile и нагрузку уже на выбранном хосте.

Текущая архитектура рассчитана на один процесс и один хост. Таймаут или перезапуск во время запроса к провайдеру может привести к повторному списанию; обработка не обещает exactly-once billing. Разбор основан на тексте и не измеряет голос, жесты или психологическую уверенность.
