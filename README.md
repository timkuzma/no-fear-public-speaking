# Сцена без страха

Сервис для репетиции выступлений на русском языке. Запишите речь, ответьте на вопросы по её содержанию и получите разбор с цитатами и рекомендациями для следующей попытки.

[Открыть сервис](https://no-fear-stage.72-56-96-17.nip.io/) · [Локальный запуск](#локальный-запуск) · [Настройки](#настройки) · [Решение проблем](#сохранение-и-решение-проблем) · [Документация](#документация)

Проект работает в режиме пилота. Для тренировки нужен аккаунт; на внешнем сервере регистрация доступна по приглашению организатора. Локально приглашение по умолчанию не требуется.

## Как проходит тренировка

1. Зарегистрируйтесь или войдите в аккаунт. Выберите длительность выступления от 30 секунд до 10 минут. Тему и пожелания к разбору можно указать по желанию.
2. Разрешите доступ к микрофону, при необходимости включите камеру и нажмите «Я готов приступать».
3. Выступите. Запись завершится по таймеру или вашей команде и сохранится автоматически.
4. Ответьте на три вопроса по сказанному в том же чате встречи. Они появляются по одному; запись ответа начинается сразу. На каждый ответ есть до минуты дополнительно к времени выступления. Вопросы можно заранее отключить в настройках.
5. Откройте разбор, прослушайте или скачайте запись. Выберите рекомендацию для повторной тренировки или начните новую тему. Сохранённые попытки доступны в истории аккаунта.

Разбор опирается на расшифровку выступления и ответов. Камера нужна для записи: AI не анализирует изображение, жесты, интонацию или психологическую уверенность. Распознавание речи и рекомендации могут содержать ошибки; независимая оценка качества рекомендаций ещё не завершена. Методика и результаты проверок — в [документации AI-разбора](docs/ai-quality-validation.md).

## Локальный запуск

Нужны Git, Python 3.12 или новее и браузер с доступом к микрофону. Node.js нужен для части тестов; сборка интерфейса и установка npm-пакетов не требуются.

### Установка

```sh
git clone https://github.com/timkuzma/no-fear-public-speaking.git
cd no-fear-public-speaking
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
```

Команды рассчитаны на macOS и Linux. В Windows используйте WSL либо замените `.venv/bin/python` на `.venv\Scripts\python.exe` и запускайте Uvicorn напрямую.

### Запуск без AI

```sh
.venv/bin/python -m uvicorn server.app:app --host 127.0.0.1 --port 8080 --workers 1 --no-access-log
```

Откройте [http://localhost:8080/](http://localhost:8080/), создайте аккаунт и разрешите доступ к микрофону. Без ключа провайдера доступны регистрация и сохранение записей; вопросы и AI-разбор требуют настройки ниже.

Интерфейс и API обслуживает один сервер. Не открывайте `index.html` как файл и не запускайте отдельный статический сервер. Для остановки нажмите `Ctrl+C`. Данные останутся в каталоге `data/`.

### Запуск с AI

Понадобится ключ провайдера с OpenAI-совместимыми методами `/chat/completions` и `/audio/transcriptions`, а также доступ к выбранным моделям. По умолчанию приложение использует агрегатор `https://shared1.multitool.works:4000/v1`; ключ другого сервиса требует соответствующего `LLM_BASE_URL`. Оплата запросов и доступ к моделям определяются вашим провайдером.

Остановите предыдущий сервер, затем выполните:

```sh
export LLM_MODEL=gpt-5.4
.venv/bin/python scripts/start_with_provider.py
```

Скрипт запросит ключ скрытым вводом и запустит приложение по тому же адресу. Ключ передаётся через окружение процесса и не сохраняется скриптом в файл. В примере явно выбран алиас `gpt-5.4` подключённого провайдера. При смене провайдера задайте его адрес и поддерживаемые имена моделей.

При уже настроенном окружении можно использовать `./scripts/run-local.sh`.

## Настройки

[`.env.example`](.env.example) содержит перечень переменных и безопасные примеры. Приложение **не загружает `.env` автоматически**: экспортируйте нужные значения в окружение процесса. Не добавляйте ключи в исходники, команды с открытым значением ключа или Git.

| Переменная | Назначение и значение по умолчанию |
| --- | --- |
| `APP_ENV` | `development` локально; `production` для внешнего сервера |
| `APP_ORIGIN` | Точный адрес сайта. Локальный скрипт задаёт `http://localhost:8080`; для production нужен HTTPS |
| `DATA_DIR` | Приватная база и записи; по умолчанию `data/` |
| `LLM_API_KEY` | Ключ AI-провайдера; передаётся только серверу |
| `LLM_BASE_URL` | Базовый URL API; по умолчанию `https://shared1.multitool.works:4000/v1` |
| `LLM_MODEL` | Модель вопросов и разбора. Для приведённого запуска — `gpt-5.4` |
| `TRANSCRIPTION_MODEL` | Модель расшифровки; по умолчанию `whisper-large-v3` |
| `FEEDBACK_EDITOR_MODEL` | Необязательная модель редактуры формулировок, например `deepseek-v3.2`. Без переменной этап выключен |
| `REQUIRE_INVITE` | `1` включает приглашения локально; production всегда требует приглашение |
| `MAX_UPLOAD_BYTES` | Максимальный размер одной записи; по умолчанию 32 MiB |
| `DAILY_JOB_LIMIT` | До 20 заданий на пользователя за скользящие 24 часа |
| `OPERATOR_TOKEN` | Отдельный секрет операторских API; production требует не менее 24 символов |
| `PORT` | Порт локальных скриптов; по умолчанию `8080` |

Лимиты запросов AI, аудио и очередей перечислены в [`.env.example`](.env.example) и [операционных инструкциях](docs/operations.md#ai-and-capacity-limits). Они ограничивают объём работы, а денежный лимит нужно задавать у провайдера.

## Сохранение и решение проблем

Завершённые записи хранятся в браузере до подтверждения загрузки на сервер. Локальные черновики можно восстановить в течение 24 часов в том же браузере и на том же адресе сайта. Для черновика аккаунта войдите в тот же аккаунт. После прерывания записи может потребоваться прослушать восстановленный фрагмент и подтвердить продолжение; последние секунды могут не сохраниться.

| Ситуация | Что делать |
| --- | --- |
| Микрофон или камера недоступны | Разрешите доступ в настройках сайта и проверьте выбранное устройство. Для локальной работы используйте `localhost`, для внешнего сервера — HTTPS |
| Вопросы или разбор не создаются | Проверьте ключ, базовый URL, доступ к обеим моделям и лимиты провайдера. После исправления повторите обработку сохранённой тренировки |
| Запись не загрузилась | Оставьте вкладку открытой и повторите сохранение. При предупреждении о недоступном локальном хранилище запись остаётся только в памяти вкладки |
| Сессия истекла | Войдите в тот же аккаунт. Сохранённые попытки доступны в истории; для новой записи снова нажмите «Я готов приступать» |
| Порт занят | Остановите другой экземпляр либо задайте `PORT=8081 ./scripts/run-local.sh` и откройте `http://localhost:8081/`. Черновики между адресами не переносятся |
| Забыли пароль | Обратитесь к организатору пилота. Автоматическое восстановление по почте пока не подключено |

Серверные записи сохраняются между перезапусками. Очистка данных браузера может удалить неподтверждённые локальные черновики; удаление `data/` удалит локальную базу и записи.

## Для разработчиков и организаторов

Проект использует FastAPI, SQLite и нативные JavaScript-модули. Запускайте один процесс приложения и одну реплику: SQLite, приватные файлы и две фоновые очереди рассчитаны на один хост. Для внешнего запуска подготовлены Dockerfile, HTTPS-прокси, инструменты выпуска, резервного копирования и отката; настройка описана в [операционных инструкциях](docs/operations.md).

### Проверки

```sh
.venv/bin/python -m pytest -q
```

Для JavaScript-проверок нужен Node.js с поддержкой ES-модулей. Обычные тесты используют временные данные и имитацию ответов провайдера. Проверка реальных AI-запросов и браузерная приёмка запускаются отдельно; команды и ограничения описаны в документации.

### Приглашения и восстановление доступа

На локальном сервере с тем же `DATA_DIR`:

```sh
.venv/bin/python -m server.cli invite --uses 1 --hours 72
.venv/bin/python -m server.cli reset participant@example.com --minutes 30
```

Коды передавайте приватно; перед восстановлением проверьте владельца аккаунта. В production выполняйте команды внутри работающего контейнера по [инструкции](docs/operations.md), чтобы не обращаться к живой SQLite из другого окружения.

### Структура проекта

| Каталог | Содержимое |
| --- | --- |
| `public/` | Поддерживаемый интерфейс, стили, изображения и локальные шрифты |
| `server/` | API, авторизация, хранение, AI и фоновые задачи |
| `scripts/` | Локальный запуск, выпуск, мониторинг и резервное копирование |
| `tests/` | Проверки сервера, интерфейса и эксплуатации |
| `evals/` | Синтетические сценарии и инструменты проверки AI-разбора |
| `deploy/` | Шаблоны HTTPS-прокси и системных служб |
| `docs/` | Техническая документация и результаты проверок |

Сервер использует интерфейс из `public/`. База пользователей, записи, ключи, резервные копии и материалы интервью не входят в репозиторий. Разовые отчёты проверок и снимки экрана сохраняются локально в `outputs/`, который исключён из Git.
