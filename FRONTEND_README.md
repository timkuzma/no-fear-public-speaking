# Интерфейс пилота

Поддерживаемый интерфейс находится в `public/`. Он использует нативные JavaScript-модули и CSS, без сборщика и внешних UI-зависимостей. Интерфейс и `/api` обслуживаются одним FastAPI-приложением; инструкции запуска — в [README](README.md).

Основные маршруты: `#/landing`, `#/example`, `#/register`, `#/login`, `#/reset`, `#/privacy`, `#/guest`, `#/app`, `#/history`, `#/practice/<id>`. Перезагрузка восстанавливает сессию через сервер и открывает сохранённую тренировку или активное задание.

`public/api.js` содержит реальный API-адаптер; CSRF хранится только в памяти вкладки. Пароли, ключи AI и сессионные токены в localStorage не сохраняются. `demoResult()` используется только для явно обозначенного открытого примера.

Гостевая запись остаётся в памяти вкладки. Авторизованная запись сохраняется на сервере, вопросы и ответы обрабатываются отдельными сегментами. AI-ожидание не входит в продолжительность речи.

Контракт интеграции — [docs/api-contract.md](docs/api-contract.md). Корневые статические копии из первоначального ZIP не являются актуальным интерфейсом.
