# Speech feedback evaluation assets

- `baseline/`: immutable pre-change source/contracts, not measured model quality.
- `corpus/`: 120 individually authored synthetic task situations (40 development / 20 calibration / 60 locked acceptance).
- `manifest.json`: immutable corpus file hashes and non-overlapping source/task family IDs; speaker identities are null because no speakers were sampled.
- `challenge-pairs.jsonl`: twenty seeded development feedback pairs and related context/polish/position perturbations; reversed order is the same paired family.
- `development-baseline-mechanical.json`: injected-provider replay observations, zero network/model calls; no semantic quality grade.
- `proposed-gates.json`: pending measured baseline and independent human calibration; acceptance remains locked.
- `critic-experiment.json`: offline research proposal only, not imported by runtime.
- `review/`: handoff instructions; blank ratings are generated by the harness, never interpreted as pass.

These are test material, not real users, recordings, expert gold, normative scoring or product testimonials. Technical identity/quote checks cannot establish entailment or usefulness. Known limitations include zero audio, zero human labels, short text in the synthetic 590-second duration case, limited scenarios and authored rather than sampled independence. Do not add these assets to public application content or return a public sample report.

See `docs/ai-evaluation-protocol.md`, `docs/speech-feedback-rubric.md` and `docs/eval-annotation-guide.md`.
